# Chanly

Название платформы — **Chanly**. MAX — название мессенджера, в котором размещается реклама.

- Бэкенд: https://github.com/leha-creator/chanly
- Фронтенд: https://github.com/leha-creator/chanly-frontend
- Исходный логотип: [chanly-logo.png](assets/chanly-logo.png). Фронтенд использует ту же картинку в public/chanly-logo.png; компактный логотип показывает её play-символ.

## Совместимость существующих окружений

Локальные каталоги D:/work/maxim и D:/work/maxim-frontend не перемещались. Имя команды maxim, cmd/maxim, переменные MAXIM_*, образы ghcr.io/leha-creator/maxim*, каталоги /opt/maxim*, базы, бакеты, Docker-тома, метрики и рабочие адреса сохранены: их переименование требует согласованной миграции развёрнутых окружений и данных. Go-модуль и ссылки GitHub используют chanly.

Ссылки на исходный макет Figma Maxim V0.1, исторические планы и ключи Tasker MAXI сохраняют исходные идентификаторы. Настройки внешних интеграций Tasker/GitHub и рабочие домены нужно проверять отдельно при следующем выпуске. Ребрендинг исходников сам по себе не выкатывает сайт.
